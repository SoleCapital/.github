<br>

A Sole Capital é uma gestora de investimentos sediada em São Paulo, com dois braços de negócio: **Asset Management**, gestão de fundos e mandatos, e **Multi Family Office (MFO)**, planejamento patrimonial e alocação para famílias. Este perfil reúne os repositórios de produto, dados e infraestrutura que sustentam a operação.

<br>

### Produtos e plataformas

| Repositório | O que é |
| :-- | :-- |
| [`wealth-cobranca`](https://github.com/SoleCapital/wealth-cobranca) | Sistema de cobrança do Wealth: calcula a taxa de administração de cada cliente, gera as planilhas de débito para XP e BTG, controla a aprovação dos assessores e apura o pagamento de rebate. |
| [`sole-suitability-fp`](https://github.com/SoleCapital/sole-suitability-fp) | Planejamento financeiro (Financial Planning) integrado à cobrança, autenticado via SSO. |
| [`sole-observability-platform`](https://github.com/SoleCapital/sole-observability-platform) | Observabilidade HTTP interna: cadastra os serviços da casa, verifica health check, guarda histórico de execuções e abre/resolve incidentes automaticamente. |
| [`Airflow`](https://github.com/SoleCapital/Airflow) | Orquestração das rotinas diárias da mesa: market data, PnL e risco, borrow, reconciliação, wealth, stock loans e comunicação. |
| [`sole-capital-design`](https://github.com/SoleCapital/sole-capital-design) | Design system da casa — tokens, componentes e telas de referência para Sole Capital e para a marca irmã Mirante. |
| [`sole-mega-brain`](https://github.com/SoleCapital/sole-mega-brain) | Base de conhecimento técnico da engenharia, guardada como código. |

### Templates

| Repositório | Quando usar |
| :-- | :-- |
| [`sole-template-simples`](https://github.com/SoleCapital/sole-template-simples) | Projetos pequenos: scripts, automações e análises de uso único. |
| [`sole-template-completo`](https://github.com/SoleCapital/sole-template-completo) | Projetos que mexem com dinheiro ou dado de cliente, ou com mais de uma pessoa contribuindo regularmente. |
